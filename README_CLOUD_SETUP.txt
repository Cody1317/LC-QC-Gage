LaserCraft QC Gages — New Supabase Project

1. In the new Supabase project, open SQL Editor -> New query.
2. Open SUPABASE_QC_GAGES_SETUP.sql from this package, copy all of it, paste it, and click Run.
3. Create a GitHub repository such as lasercraft-qc-gages.
4. Upload the website files from this package.
5. GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root).
6. Open the GitHub Pages address and confirm “Shared QC database connected ✓”.

IMPORTANT: Back up the existing QC Gages app before replacing it if it contains important local records.
Existing browser-stored calibration PDF files are not migrated to Supabase Storage in this version.
